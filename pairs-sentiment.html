Currency Pair Sentiment (bp)

Pair sentiment compares the expected policy-rate change in basis points for the base and quote currency at the next meeting. If the base currency has a higher bp value than the quote currency, the pair gets ▲; if lower, ▼; if equal, =. A change in direction is flagged.
