Currency Pair Sentiment (bp)

Pair sentiment compares the expected policy-rate change in basis points for the base and quote currency at the next meeting. The Difference is base bp minus quote bp. Move sentiment compares how much each currency moved since its last change (base move minus quote move).

Difference (bp) = base bp minus quote bp, with the date and time of its last sentiment change below it. Base move / Quote move = how much each currency's bp has risen (▲) or fallen (▼) since 00:00 Warsaw time today. DIFFERENCE MOVE = base move minus quote move in bp, with the time of the latest move. MOVE SENTIMENT = arrow only: ▲ if the advantage is with the base currency, ▼ if it is with the quote currency, = if equal. DAY DIFFERENCE MOVE = the DIFFERENCE MOVE of one whole day, closed once at 00:00 Warsaw time (the date it covers and the time it closed are shown) and kept until the next close. It is not accumulated across days. Values are calculated and stored on the server (Cloudflare Worker), not in your browser.
